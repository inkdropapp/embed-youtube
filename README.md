# embed-youtube

Embed YouTube videos in [Inkdrop](https://www.inkdrop.app/) notes.

Paste a YouTube link and it renders as an embedded video player in the preview. A paste-link format option lets you quickly insert the iframe HTML directly in the editor.

## Features

- Renders YouTube videos inline in the Markdown preview
- Supports `youtube.com/watch?v=...` and `youtu.be/...` URLs
- Adds a "YouTube embed" option to the paste-link autocomplete menu for inserting iframe HTML

## Install

```
ipm install embed-youtube
```

## Usage

1. Paste a YouTube URL on its own line in a note
2. The preview will render it as an embedded video player
3. When pasting a YouTube URL, select **YouTube embed** from the autocomplete menu to insert the iframe HTML directly
